A one-line fridge roast, printed by a tiny Python program. Open the fridge at midnight hoping for a miracle, and this is what answers back: a hum, a light, a 2019 ketchup, and one carrot that filed for retirement.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and nothing else.
